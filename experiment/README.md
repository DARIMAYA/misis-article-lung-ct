# Эксперименты

Здесь лежат результаты и описание протокола. Ноутбуки Kaggle/Colab (UNet 3+, nnU-Net, EfficientNet, Swin) положите рядом и укажите ссылки в этом файле.

## Данные

- Сегментация: LIDC-IDRI, подвыборка lidc-148 — 148 пациентов (48 с узлами, 100 без). Разбиение по пациентам 103/22/23, стратификация по наличию узлов. Эталон — консенсусная маска (≥3 из 4 рентгенологов).
- Классификация: Chest CT-Scan Images (Kaggle).

## Зафиксированный протокол

- UNet 3+ (3D): фильтры (32, 64, 128, 256), cat_ch = 32, 14,69 млн параметров, патч 64³, batch 2, AdamW, Tversky + Focal, ReduceLROnPlateau, AMP.
- Предобработка и вывод: окно −1000…400 HU, нормировка `(clip(vol, −1000, 400) + 1000) / 1400`, воксель 1×1×1 мм; предсказание возвращается в исходную сетку обратным отображением.
- nnU-Net v2: 3d_fullres, fold 0, `nnUNetTrainer_100epochs`.
- Метрики: DSC, IoU, чувствительность, точность, специфичность (сегментация); accuracy, F1 (классификация).

## Результаты

См. `results.csv`. Пустые значения означают, что тест ещё не получен; числа в статье берите только отсюда. Все записи со статусом `preliminary` — единичные запуски на малой выборке.

## Воспроизведение

1. Запустить ноутбук сегментации до ячейки 10 (вывод скользящим окном и подсчёт метрик на тесте).
2. Занести значения в `results.csv` и таблицу IV в `article.tex`.
3. Для доверительных интервалов — повторить запуски с разными seed.
